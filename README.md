### Como Usar / How to Use

> [!NOTE]
> **English speakers:** Check the dropdown below for the translated step-by-step guide.

<details>
<summary><b>Click here for the English version</b></summary>
<br>

1. On AO3, go to *My Dashboard > Skins > Create Work Skin*.
2. Copy all the code from the `business-cards.css` file in this repository and paste it into the CSS box of your Work Skin.
3. In the editor of your AO3 chapter, select the created Work Skin and paste the desired code snippet from `business-cards.html`.

<hr>
</details>
<br>

1. No AO3, vá em *My Dashboard > Skins > Create Work Skin*.
2. Copie todo o código do arquivo `business-cards.css` disponível neste repositório e cole na caixa de CSS da sua Work Skin.
3. Na aba do seu capítulo no AO3, selecione a Work Skin criada e em seguida cole o snippet de código desejado do arquivo `business-cards.html` no seu capítulo.

> [!TIP]
> Deixei os códigos organizados por pastas neste repositório para facilitar a cópia rápida!
